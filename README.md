## 報名資料存在哪裡

「團報/團購繳費記錄」試算表的 **「順發港都團報」** 工作表（收件程式只會動這一張，其他工作表、試算表本身的團購程式都不會動）。

| 欄 | 內容 |
|---|---|
| A–J | 跟 NID 繳費記錄同格式：編號、姓名、匯款日期、班別、費用、後五碼、報名賽事、NID學員朋友名字、是否為當期學生（打勾）、備註 |
| K–O | 已對帳（勾選）、Email、行動電話、費用明細、送出時間 |
| P–AE | **大會團報表「團員名單」B–Q 欄**，順序一樣；Y、Z 改放**緊急聯絡人、緊急聯絡人電話**（大會表 K、L 欄的標題是保證人身分證、保證人姓名） |

有人取消就刪掉那一列。

## 匯出給大會（不用程式）

1. 刪掉【測試】的列（或在 Apps Script 編輯器選 `deleteTestRows` → 執行，只會刪姓名以【測試】開頭的列）。
2. 選取已對帳的人的 **P–AE**（不含標題）→ 複製。可以先用「資料 > 建立篩選器」只顯示 K 欄打勾的人。
3. 把大會的「團體報名表」Excel 上傳到 Google 雲端硬碟、用 Google 試算表開啟，點「團員名單」的 **B3** → 貼上。
4. 「團體聯絡人資料」填團隊聯絡人（郵寄地址記得用新的）。
5. 檔案 > 下載 > Microsoft Excel (.xlsx)，上傳到樂活報名平台。

直接用 Excel 貼的話請用「選擇性貼上 > 值」，電話、生日才不會被 Excel 改掉。
「抬頭／統編」（V、W 欄）程式不會填；要開公司發票的話，匯出前整欄往下填。
「得知訊息來源」（AC 欄）預設每個人都是 `05.line群組`，要改就改 Code.gs 的 `SOURCE`。

## 收件程式（apps-script/Code.gs）

- 很多人同時送出：收件程式一次寫一筆（最多排隊 30 秒），確認信等寫完、排隊結束後才寄；
  排不到或 Google 回錯誤時，網頁會自動等 2–5 秒重送（最多 3 次）。同一個證件號碼重送會被擋下，不會重複報名。
  首頁的報名人數快取 30 秒，有人報名就馬上更新。目前部署的是第 3 版（2026/11/21：保證人兩欄改成緊急聯絡人、緊急聯絡人電話）。

- 是**獨立**的 Apps Script 專案（nid@nidrc.com 的 script.google.com），用試算表 ID 打開「團報/團購繳費記錄」，不綁在試算表上。
- 報名確認信：`CONFIG.MAIL`（寄件人名稱）、`SITE_URL`、`LINE_ID`、`BANK`；不要寄信就把 `MAIL.enabled` 改成 false。
- 第一次：貼上程式 → 執行 `setup`（授權）→ 部署 → 新增部署作業 → 網頁應用程式（執行身分：我／存取：所有人）→ 網址貼到 `config.js` 的 `endpoint`。
- 之後修改 Code.gs：部署 → 管理部署作業 → 鉛筆 → 版本選「新版本」→ 部署（網址不變）。
- 會再檢查一次：組別年齡（21K 須滿 16 歲、健走組 8 歲以上、兒童組未滿 8 歲）、每個人都要填緊急聯絡人和電話（不能填自己、不能和自己的手機相同）、旅平險 15–85 歲、同一證件只能報一次、金額由程式重算（跟網頁不同會在備註標 ⚠）。
